# Reference and model fidelity

The user's multi-view image depicts a red Ferrari 812 Superfast with a long sculpted bonnet, pronounced front fenders, a rearward coupe cockpit, curved rear shoulders, a deep door-side channel, black double-spoke wheels, yellow calipers, elongated headlights and four round rear lamps.

The first generated exterior was too flat and angular. The current version uses Jayrenn Reeve's artist-authored CC0 812 body, retaining modeled hood ridges, fender bulges, recessed vents, coupe roof and door contours. Runtime wheels are generated reference-style double spokes with yellow calipers; shared paint, glass and lighting were adjusted in real browser renders.

The image is a styling reference, not measured engineering data. Hidden engine/suspension geometry is inferred. The source is not a scan or official Ferrari CAD. Roof and rear quarters remain one continuous shell; no arbitrary cuts were introduced to inflate part count.

Actual desktop renders of front, rear, side, top, studio, cockpit, wheels and engine were reviewed. See TEST_RESULTS.md for current functional checks and limits. No bitmap replacement is used for the interactive car.
