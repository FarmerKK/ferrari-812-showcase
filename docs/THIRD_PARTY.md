# Assets and dependencies

All car geometry, the fictional circuit, textures for asphalt/grass/carbon, signs and the atelier badge were authored procedurally in this project. No third-party Ferrari mesh, game asset, paid model or HDRI was incorporated. The source image remains the user-supplied design reference; its original attachment is not redistributed as a site image.

| Dependency | Installed version | License |
| --- | --- | --- |
| Three.js | 0.180.0 | MIT |
| GSAP | 3.15.0 | [GSAP Standard no-charge license](https://gsap.com/standard-license/) |
| Lucide | 0.468.0 | ISC |
| Vite | 7.3.7 | MIT |
| Barlow Condensed / DM Sans | Google Fonts delivery | SIL Open Font License; external CSS request, local sans-serif fallback |

The native import option lazy-loads Draco decoders from Google's versioned CDN only when needed. No provider credentials are bundled in the website. Ferrari vehicle naming and the reference are used for the independent descriptive showcase; the custom 'A' atelier badge is not the Ferrari logo.
